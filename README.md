# Modrinth CurseForge Integration

A personal, non-commercial modification of the open-source Modrinth App.

## Project Goal

Integrate CurseForge support into Modrinth App, allowing Minecraft mods and modpacks from both platforms to be browsed, downloaded, installed, and managed in one application.

## Project Status

Currently in development. The project is intended exclusively for personal use and is not planned for public distribution.

## CurseForge API

CurseForge integration is being developed using the official API, subject to API access approval and mod authors' distribution permissions.

## Disclaimer

This is an independent personal project and is not affiliated with or endorsed by Modrinth or CurseForge.
